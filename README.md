# 🌱 EcoTech Solutions

# Sobre o projeto
A EcoTech Solutions é uma empresa fictícia desenvolvida para um projeto acadêmico do curso de Análise e Desenvolvimento de Sistemas (ADS). O site apresenta serviços de tecnologia com foco em inovação e sustentabilidade.

# Objetivo
Criar um site com várias páginas para apresentar a empresa, seus serviços e seus canais de contato.

# Tecnologias utilizadas
- HTML5
- CSS3

# Páginas do site
- **Início:** apresentação da empresa.
- **Sobre:** informações sobre a EcoTech Solutions.
- **Serviços:** apresentação dos serviços oferecidos.
- **Contato:** página para contato com a empresa.

# Arquivos do projeto
- `inicio.html`
- `sobre.html`
- `serviços.html`
- `contato.html`
- `style.css`

# Como executar
Baixe os arquivos do projeto e abra o arquivo `inicio.html` em um navegador.

## Projeto acadêmico
Desenvolvido para fins educacionais.
